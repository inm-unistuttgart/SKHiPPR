Visualization#

The following modules offer SKHiPPR internal methods for visualizing equilibria and periodic solutions of solved equations.

All visualization functions accept as first argument either a certain AbstractEquation object (depending on the visualization function) or an EquationSystem containing one. When an EquationSystem is passed, the first applicable AbstractEquation within it is visualized.

Calling the visualization functions directly with only an AbstractEquation or EquationSystem as input creates and returns a matplotlib.axes.Axes object for each plot. Alternatively, passing an existing Axes object uses that axes for plotting and returns it.

The supported equations and equation systems are indicated below.

Methods for visualizing continuation solutions are currently under construction.

visualization.equilibria#

The equilibria module offers standardized functions for visualizing equilibria as well as equilibrium eigenvalues. Supported equations are instances of classes implementing AbstractODE as well as EquationSystem instances that contain such an object.

It provides the function plot_equilibrium() for plotting the equilibrium in a standard x-y plane and plot_eigenvalues() for making plots of the equation eigenvalues in the complex plane.

skhippr.visualization.equilibria.plot_equilibrium(ode: AbstractODE | EquationSystem, ax=None, idx: Sequence[int] = [0, 1], **plot_kwargs)#

Plot the equilibrium of an ordinary differential equation.

Parameters:

  • ode (AbstractODE or EquationSystem) – The ordinary differential equation or an equation system containing it.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, a new Axes instance will be created.

  • idx (Sequence[int], optional) – Exactly two indices of the states to be considered

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with the equilibrium.

Return type:

matplotlib.axes.Axes

skhippr.visualization.equilibria.plot_eigenvalues(ode: AbstractODE | EquationSystem, ax=None, **plot_kwargs)#

Plot the eigenvalues of an ordinary differential equation. If no matplotlib.axes.Axes object is passed, the function wil also plot the imaginary axis.

Parameters:

  • ode (AbstractODE or EquationSystem) – The ordinary differential equation or an equation system containing it.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, a new Axes instance will be created.

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with the the plotted eigenvalues.

Return type:

matplotlib.axes.Axes

visualization.cycles#

The cycles module provides standardized functions for visualizing limit cycles over multiple periods, their phase portraits as well as Floquet multipliers and exponents.

Supported equations are instances of HBMEquation or HBMSystem that contain such an equation.

It provides the functions plot_period() for plotting the time series of the equation solution, plot_phase() for making phase portraits and plot_floquet_multipliers() as well as plot_floquet_exponents() for visualizing the floquet multipliers and exponents of a cycle.

skhippr.visualization.cycles.plot_period(hbm: HBMEquation | HBMSystem, ax=None, idx=0, n_periods: float = 1.0, **plot_kwargs)#

Plot the time series of a solved HBMEquation over a given number of periods.

Parameters:

  • hbm (HBMEquation or HBMSystem) – The equation or equation system containing the solution. If it is of type HBMSystem, the first valid HBMEquation instance contained is used.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, an Axes instance will be created.

  • idx (int, optional) – The index of the state to be plotted.

  • n_periods (float, optional) – The number of periods for which the time series is plotted. May be non-integer.

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with the plotted period response.

Return type:

matplotlib.axes.Axes

skhippr.visualization.cycles.plot_phase(hbm: HBMEquation | HBMSystem, ax=None, idx: Sequence[int] = [0, 1], **plot_kwargs)#

Plot the phase of a solved HBMEquation.

Parameters:

  • hbm (HBMEquation or HBMSystem) – The equation or equation system containing the solution. If it is of type HBMSystem, the first valid HBMEquation instance contained is used.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, a new Axes instance will be created.

  • idx (Sequence[int], optional) – Exactly two indices of the states to be considered, for example [0,1] for standard x-y phase plane

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with the phase plot.

Return type:

matplotlib.axes.Axes

skhippr.visualization.cycles.plot_floquet_multipliers(hbm: HBMEquation | HBMSystem, ax=None, **plot_kwargs)#

Plot the Floquet multipliers of the HBMEquation solution.

Parameters:

  • hbm (HBMEquation or HBMSystem) – The equation or equation system containing the solution. If it is of type HBMSystem, the first valid HBMEquation instance contained is used.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, a new Axes instance will be created.

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with a scatter plot of the Floquet multipliers on the complex plane. A unit circle is also plotted, if no axes is given in the call.

Return type:

matplotlib.axes.Axes

skhippr.visualization.cycles.plot_floquet_exponents(hbm: HBMEquation | HBMSystem, ax=None, **plot_kwargs)#

Calculate and plot the Floquet exponents of the HBMEquation solution from the Floquet multipliers.

Parameters:

  • hbm (HBMEquation or HBMSystem) – The equation or equation system containing the solution. If it is of type HBMSystem, the first valid HBMEquation instance contained is used.

  • ax (matplotlib.axes.Axes, optional) – The Axes object on which to plot. If None, a new Axes instance will be created.

  • **plot_kwargs – Additional keyword arguments passed to ax.plot().

Returns:

ax – The Axes object with a scatter plot of the Floquet exponents on the imaginary plane.

Return type:

matplotlib.axes.Axes
